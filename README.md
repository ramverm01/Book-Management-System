The Book Management System is a simple and efficient application designed to manage books in a library or personal collection. This system allows users to add, update, delete, search, and view books easily.
This project is built using Core Java, JDBC, MySQL, HTML, and CSS to demonstrate database connectivity and CRUD operations in a clean and structured way.

✨ Features
✅ Add New Books
✅ View All Books
✅ Search Books by ID / Name
✅ Update Book Details
✅ Delete Books
✅ User Friendly Interface
✅ Database Connectivity using JDBC

🛠️ Technologies Used
☕ Core Java
🗄️ MySQL Database
🔗 JDBC
🌐 HTML
🎨 CSS
💻 Eclipse IDE
